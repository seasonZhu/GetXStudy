# 领域文档

## 布局与读取规则

本仓库采用单上下文布局：
- 根目录 GLOSSARY.md：领域词汇表。
- docs/adr/：架构决策记录。

探索代码前，读取词汇表及与当前任务相关的 ADR。
若根目录存在 GLOSSARY-MAP.md，则按映射读取相关上下文的词汇表。

文档不存在时直接继续，不提示缺失，也不提前创建占位文档。
由 domain-modeling 在术语或决策明确后按需创建。

## 术语一致性

任务标题、重构建议、假设和测试名称使用词汇表定义的术语，
避免使用词汇表明确排除的同义词。
遇到未收录的概念，先确认是否符合项目用语；
确有缺口时记录为 domain-modeling 的待办。

## 决策冲突

建议与已有 ADR 冲突时，明确指出相关 ADR 和重新讨论的原因，
不得静默覆盖已有决策。
