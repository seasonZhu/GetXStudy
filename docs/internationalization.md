# 国际化说明与验收

## 语言与切换

支持简体中文（zh_CN）、英语（en_US）、法语（fr_FR）。首次启动跟随系统首选语言列表，按语言代码匹配地区变体；所有 zh 变体使用简体中文，没有可匹配语言时回退英语。

语言设置提供“跟随系统”和三种语言的原文名称。手动选择保存在 SharedPreferences 的 `app.language`，取值为 zh、en、fr；跟随系统时删除该键。缺失或无效偏好按跟随系统处理。设置独立于账户和主题，退出登录不清除语言。

语言服务在 runApp 前恢复设置和日期资源。运行时切换使用 GetX 更新现有元素树，保留导航器、控制器、输入及已有数据；系统语言变化只影响跟随系统模式。

## 文案维护

- `lib/i18n/zh_cn.dart`、`en_us.dart`、`fr_fr.dart` 是应用文案源，键集合及命名参数必须一致。
- `LocalizedStrings` 向 GetX 提供资源；普通文案使用 `AppText.t`，数值和日期使用 `AppText.number`、`AppText.date`。
- 不缓存翻译后的状态文案。积分摘要保存数值，显示时按语言生成；调试筛选使用稳定键，显示标签再翻译。
- `AppStrings` 的 init、of、direct 及快捷 getter 保留，统一读取当前翻译；原固定中文 JSON 已移除。
- 整句中的变量使用 `@name` 参数。秒数使用 `AppText.seconds`，包含英语及法语的数量形式。
- 本地 HTML 资源由 `dart tool/generate_html_localizations.dart` 生成 `assets/html/localization.js`。修改 html 词条后重新生成，测试会检查资源与源词条一致。
- 欢迎页内嵌中文图片已改为真实文字布局。其余正在使用的静态图片没有需翻译的说明文字。

## 覆盖与保留边界

已覆盖业务页、公共加载/空态/错误/刷新组件、示例页、自有调试筛选与分享界面、图标辅助功能名称、本地 HTML，以及 Flutter Material/Cupertino/刷新组件的本地化配置。

iOS 相机、照片读取和照片保存用途说明提供三语 InfoPlist.strings 并加入资源构建；macOS 原生菜单提供三语 MainMenu.strings。Android 自有原生可见文案仅应用名称，保留原品牌。

以下内容保留原文：

- 服务端文章、分类名称、用户输入、第三方网页和应用品牌名称。
- 服务端返回的未知错误描述，不通过匹配中文内容猜测错误类型；已知客户端网络异常及 HTTP 状态兜底提示提供本地化。
- 调试日志正文、历史事件和 Talker 自动生成的技术字段保留原始诊断内容。自有查看器的按钮、筛选、空态及分享失败提示提供三语；未接入第三方 Talker 原生查看器的额外翻译。
- 未使用的旧账户管理示例及枚举测试数据不作为运行界面文案处理。

原生权限弹窗、系统分享界面和 macOS 原生菜单受平台及系统语言规则控制，应用内切换不承诺立即改变它们。无真实设备或模拟器人工验收记录。
